# Body Drag

<img width="1672" height="941" alt="bodydrag-miniature3" src="https://github.com/user-attachments/assets/499c4a83-821f-4977-ae5e-6db641c747bf" />

Traîner un joueur mort/inconscient au sol, avec animations synchronisées entre le traîneur et la victime.

## Installation

1. Copier le dossier de la resource dans `resources/`.
2. Ajouter `ensure bodydrag` (ou le nom du dossier) dans `server.cfg`.
3. Ajuster `config.lua` si besoin (voir ci-dessous).

## Commandes de test (uniquement si `Config.Debug = true`)

- `/dragtest` — fait apparaître un PNJ mort devant vous.
- `/dragtestclear` — supprime les PNJ de test et réinitialise l'état du drag.
